隐私权政策（Privacy Policy）

最后更新日期：2026年11月27日

欢迎访问 Tayino（网址：https://tayino.com，以下简称“本网站”或“我们”）。我们非常重视您的个人隐私与数据安全。本隐私权政策旨在说明当您使用本网站及通过 Google 账号登录（Google OAuth）时，我们如何收集、使用、存储和保护您的信息。

1. 我们收集的信息

当您选择使用 Google 账号登录本网站时，经您明确授权，我们会通过 Google OAuth 接口获取以下基本个人资料信息：

  • 基本账户信息：您的电子邮箱地址（Email）、姓名/显示名称以及个人头像链接。
  • 技术与日志信息：为保障网站安全与正常运行，我们可能会收集基本的访问日志（如 IP 地址、浏览器类型及访问时间）。

2. 信息的使用目的

我们收集上述 Google 用户数据仅用于以下必要目的：

  • 创建、识别并管理您的 Tayino 用户账户，实现一键安全登录；
  • 向您提供本网站的核心功能及必要的账户通知服务；
  • 维护平台安全，防范欺诈及未经授权的访问。

3. Google 用户数据的共享、转让与披露

  • 绝不出售数据：我们绝对不会将您的个人数据或通过 Google API 获取的信息出售、出租或交易给任何第三方。
  • 严格限制共享：除法律法规要求或为提供基础技术托管服务（如云端数据库存储，且受严格保密协议约束）外，我们不会向任何第三方共享您的 Google 用户数据。
  • 合规声明：本网站对从 Google API 接收到的信息的使用与传输，均严格遵守 Google API 服务用户数据政策（Google API Services User Data Policy），包括其中的“有限使用（Limited Use）”要求。

4. 数据存储与安全保护

  • 您的账户信息存储于受安全加密保护的服务器中，我们采取行业标准的安全措施（包括 HTTPS 加密传输及访问权限控制）防止数据泄露、篡改或丢失。
  • 我们仅在为您提供服务所需的期限内保留您的账户信息。

5. 您的权利与数据删除

您可以随时管理或撤销本网站对您 Google 账号的访问权限：

  • 撤销授权：您可以随时前往您的 Google 账号安全设置页面 移除对 Tayino 的授权。
  • 删除账户与数据：如果您希望删除在本网站的账户及所有关联个人数据，请通过下方联系邮箱与我们联系，我们将在收到请求后的 7 个工作日内处理完毕。

6. 隐私政策的更新

我们可能会适时更新本隐私权政策。更新后的版本将在本页面发布并注明最新更新日期。

7. 联系我们

如果您对本隐私权政策或您的数据隐私有任何疑问，请通过以下方式联系我们：
