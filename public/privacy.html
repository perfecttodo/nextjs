隱私權政策（Privacy Policy）

最後更新日期：2026年11月27日

歡迎使用由 Tayino（網址：https://tayino.com，以下簡稱「本網站」或「我們」）營運的「快樂小讀者（Happy Reader）」互動式多語伴讀點讀故事應用。我們高度重視家庭與兒童的個人隱私與數據安全。

1. 本地優先與我們收集的信息

  • 無需註冊與本地存儲：本應用無需註冊帳號即可使用。所有學習偏好、家庭成員配置及兒童跟讀/陪讀錄音紀錄預設均安全保存於您的裝置本機中，不會自動上傳至我們的伺服器。
  • 可選的 Google 帳號與 Google Drive 授權：僅當家長或輔導者主動啟用「Google Drive 雲端同步」功能時，經您明確授權，我們會透過 Google OAuth 獲取您的基本帳戶識別信息（如電子郵箱）及指定的 Google Drive 資料夾存取權限。

2. Google API 數據的使用目的

我們透過 Google API 獲取的授權與數據僅用於以下單一、必要目的：

  • 在您指定的 Google Drive 資料夾中備份、同步及還原家庭陪讀音頻與學習進度紀錄；
  • 協助多孩家庭在不同裝置間安全轉移故事閱讀與錄音資料。

3. Google 用戶數據的共享、轉讓與合規聲明

  • 絕不收集或出售家庭錄音：您的家庭陪讀與跟讀音頻僅存儲於您的本機或您個人授權的 Google Drive 雲端硬碟中，我們不會在自有伺服器留存、監聽、出售或向任何第三方披露您的錄音與 Google 用戶數據。
  • Google 有限使用政策合規：本應用對從 Google API 接收到的信息之使用與傳輸，均嚴格遵守 Google API 服務用戶數據政策（Google API Services User Data Policy），包括其中的「有限使用（Limited Use）」要求。

4. 兒童隱私與家長控制

  • 本應用專為多孩家庭伴讀設計，雲端同步等外部帳號授權功能僅限家長或成年輔導者操作開啟。
  • 家長可隨時在應用程式內清除本機錄音與偏好設定，或前往 Google 帳號安全設定頁面 隨時撤銷對 Tayino 的存取授權。

5. 聯繫我們
